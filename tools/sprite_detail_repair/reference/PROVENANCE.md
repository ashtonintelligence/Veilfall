# Reference provenance

Native unit and terrain PNGs were extracted without alteration from the packed
Tilesets atlas of yairm210/Unciv at commit
`3318515bfca2609a9edb127b59cfadbab6d58d38` (Unciv 4.22.4).
See `UNCIV-LICENSE.txt` and upstream art attribution for applicable licensing.

Files named only for custom units are unchanged 256×256 UnitPortrait regions
extracted from Veilfall v0.2.11's v021 atlas at
`de02479f97a367e8a12c40a8feb14beb9428ba27`. They guide identity and equipment;
they are not the new runtime artwork.

The original Veilwarden style reference remains in its existing repository path.
All references are used for traceable comparison, not as visual-acceptance claims.
